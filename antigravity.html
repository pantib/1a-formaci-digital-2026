Aquesta mateixa web que esteu utilitzant avui ha estat creada per la Comissió Digital amb l'assistent Antigravity. I la millor notícia: qualsevol persona del claustre pot aprendre a fer-ho!

👇 Descobrir la proposta de taller

🔍 Com hem creat aquest recurs educatiu?

Fins fa poc, dissenyar una web interactiva amb formulari anònim, gràfiques dinàmiques per a projector i disseny accessible WCAG AA requeria coneixements tècnics avançats. Amb eines d'IA agèntica com Antigravity, el procés se centra en la pedagogia:

🧠

1. El criteri docent és la guia

L'equip docent defineix l'objectiu pedagògic, el cicle educatiu, les preguntes i l'enfocament DUA. La IA no decideix: l'educació és al nostre comandament.

💬

2. En llenguatge natural

Descrivim el recurs que necessitem amb paraules clares: «Volem un espai per al projecte de l'aigua amb un mapa interactiu i fitxes imprimibles».

✨

3. Codi net i sostenible

Genera codi web estàndard llest per allotjar gratuïtament a GitHub Pages o a la web del centre, sense anuncis ni dependències privatives.

🎒 Quins recursos es poden crear per a l'aula?

Podeu construir en una sessió pràctica recursos a mida per al vostre grup a l'Escola Giroi:

🌿

Web per a una Situació d'Aprenentatge

Un espai digital on l'alumnat troba el repte inicial, els enllaços d'investigació, vídeos i la rúbrica d'autoavaluació per seguir el projecte pas a pas.

🎮

Joc interactiu per racons

Un trivial o joc de preguntes autocorrectiu per a la setmana cultural o per consolidar sabers de coneixement del medi de manera lúdica.

♿

Espai DUA de lectura adaptada

Lectures amb controls per canviar la mida del text, escoltar el text en veu alta i consultar termes amb suport de pictogrames.

👨‍👩‍👧

Mural digital de projecte amb les famílies

Un espai visual on compartir les creacions, les fotografies dels processos i els aprenentatges del grup d'una manera neta, segura i sense publicitat.

Proposta per al claustre

🚀 Taller pràctic: «De la idea al web educatiu amb Antigravity»

Una sessió de formació de 2 hores, 100% vivencial, dinamitzada per la Comissió Digital de l'Escola Giroi, on cada persona podrà crear el seu propi recurs web operatiu.

Què farem en aquesta sessió?

  • Zero por al codi: Com donar instruccions pedagògiques clares (prompts d'arquitectura web) a Antigravity.
  • Personalització: Aplicar els colors, la identitat gràfica i els continguts curriculars de cada nivell.
  • Publicació en un sol clic: Com allotjar el web a GitHub Pages de manera gratuïta i autònoma.
  • Banc de plantilles: Marxar amb un recurs adaptat a l'aula a punt per compartir amb l'alumnat.
